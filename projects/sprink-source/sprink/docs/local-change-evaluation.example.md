# Synthetic local-change evaluator oracle

Run with `pnpm rules:evaluate docs/local-change-evaluation.example.json`. The fixture resolves the SF permit scope to NFPA 13-2025, then moves a represented route from one 4.00 m straight segment through a fixed duct envelope to a five-segment orthogonal route with four explicit elbows. Both plans retain the same room, ceiling, duct box, coordinate frame, and tie-in IDs and coordinates.

Expected geometry: proposed centerline length is 6.00 m. The fixture supplies a 0.030 m net takeout at each of eight elbow ports, yielding 5.76 m proposed cut length; baseline cut length is 4.00 m. The aggregate route delta is +4 pipe segments, +4 elbows, and +1.76 m cut length. Derived BOM rows show one removed baseline pipe (−1, −4.00 m), five added pipes (+1 each, with cut lengths 0.97, 0.94, 1.94, 0.94, and 0.97 m), four added elbows (+1 each), and one unchanged head. The baseline straight-pipe envelope intersects the duct box; the proposed straight-pipe envelopes clear it. This is only a synthetic centerline/cut arithmetic and straight-pipe-to-box geometry oracle. It does not assess elbow body clearance, sprinkler discharge obstruction, supports, hydraulic adequacy, or overall code compliance.

Every evidence record and every fact in the JSON is marked as fixture data; none describes an actual permit, approved drawing, installation, calculation, or inspection. In particular, the 0.0081 m thread-makeup value and pressure fixture values are not validated project selections. A source-backed candidate comparison still needs exact product/revision selection, applicable temperature conditions, and confirmed joint compatibility. The fixture intentionally leaves hydraulic recalculation and part-pressure suitability unresolved. I.14(D) is not triggered because the proposed drawing says the head will not be reused; I.15 is represented as included in the proposal drawing, which resolves only that drawing-content check.
